01｜任务：借爆款的需求，寻找第二次购买

选择美国宠物自动喂食器作为宿主。研究目标是配件、清洁维护、适配和场景补充，不是复制主机。预算和供应商报价尚未给定，因此本轮不计算确定利润、不建议备货。

研究路径：候选筛选 → 销售与达人验证 → 原始评论 → 补位假设 → Amazon 搜索与竞争 → 专利线索 → 保留或淘汰 → 下一轮实验。

**数据边界：**初始候选3个，深挖1个宿主；TikTok评论10条、Amazon配件评论10条；视频3条；两轮竞品共8条；关键词挖掘2轮、关键词月趋势1条；专利语义检索3条并批量查询状态。小样本调查不能代表全市场。

04｜评论里，出现了与预设剧情不同的问题

读取宿主最新10条已收录评论，覆盖2026-10-10至11-06，按评论ID去重。评论查询total=136，商品列表评价数282，二者口径不同，不混作分母。

**线索A：水和电线的位置。**一条五星评论写到猫玩水后电线被打湿，并希望改善走线。它证明至少有一位使用者遇到该场景；不证明问题普遍，也不证明其愿意为配件付钱。

**线索B：配网与日程保存。**一条低分评论反映网络断连和App日程未保存，另有设置困难描述。这类问题不能直接被包装成“买一个实体附件就能解决”。

**线索C：尺寸适配。**Amazon PADOOR喂食垫的10条已收录评论中，出现“Wish I had bought a larger one”及“Way too small for large dog bowls”等表述。它们来自另一商品、不同平台，支持喂食区域尺寸适配这一类目线索，不能归因到Geoorood主机。

重要时效限制：这批Amazon评论日期为2025-10-25至11-09，比本次调查早约一年。不能称为近期投诉趋势。

**没有方向被批准进入备货。**值得继续的是“适配与易清洁到底能否创造额外价值”这个问题，而不是已经确定了一个赚钱产品。

08｜下一轮最小实验

  1. 访谈5名自动喂食器使用者，记录真实摆放、清洁和走线。人数为探索性实验设置，不是统计代表性样本。
  2. 先用通用喂食垫和理线件作对照。若现成配件已足够解决问题，停止开发专用件。
  3. 获取实际型号尺寸，验证抽出清洁是否方便、是否积水、是否干涉散热或进食。不得宣称未经测试的防水、电气安全性能。
  4. 拿到报价后再算单位经济。采购及头程上限＝售价×（1－平台费率－目标贡献利润率）－履约－广告－售后预留；税费和固定成本另计。当前没有费用数据，不填虚构利润。
  5. 仅当用户愿为额外价值付费、方案有效且报价可承受时，再决定打样数量。专利与必要合规核查继续进行。
